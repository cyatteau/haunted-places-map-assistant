# Contributing

Thanks for checking out Haunted Places Assistant.

This repo is also meant to be a fun place to practice GitHub collaboration basics:
- creating a branch
- making a small change
- opening a pull request
- responding to feedback

## Good ways to contribute
- Add suggested prompts
- Improve README wording
- Add screenshots
- Improve layout
- Fix small bugs

## Suggested workflow
1. Fork the repo or create a branch
2. Make one focused change
3. Open a pull request with a clear title and description
