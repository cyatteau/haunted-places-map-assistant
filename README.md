# Haunted Places Assistant

A fun ArcGIS AI components demo for exploring haunted places in the U.S. with a map assistant.

## What it does

This app lets you ask the map questions about haunted places and watch the assistant navigate, filter, and explore the data.

## Built with

- ArcGIS Maps SDK for JavaScript 5.0
- ArcGIS AI components (beta)
- Calcite components
- A haunted places web map / feature layer

## Important notes

This project uses ArcGIS AI components, which are currently in beta.
Depending on your ArcGIS Online setup, some features may require organization settings or a signed-in named user.

## Run it locally

1. Clone or download this repo
2. Open the project in a local server
3. Load `index.html`
